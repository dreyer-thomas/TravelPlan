Tried three fixes: ESLint 9→10 (breaks — bundled `eslint-plugin-react` uses an API ESLint 10 removed), forcing `brace-expansion` to v5 (crashes ESLint's glob matcher), forcing `minimatch` to v9 (doesn't crash but silently changes ignore-pattern matching, surfacing false-positive lint errors). devDependency-only, never ships, requires attacker-controlled glob input to trigger — unexploitable in this repo. `npm audit --omit=dev` is 0; this is the sole remaining finding in the full audit.
